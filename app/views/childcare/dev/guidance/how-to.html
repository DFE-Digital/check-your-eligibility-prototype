Manage eligibility for childcare support: using the service

Manage eligibility for childcare support is one of two services that have replaced the eligibility checking system (ECS). Local authorities can use this service to manage and check eligibility for:

  • early learning for 2-year-olds
  • early years pupil premium
  • childcare for working families

This guidance explains how to use the new service.

We are still developing this service. Your feedback will help us improve it.

1. How to access the service

Users at local authorities will need a DfE Sign-in account to use this service. If you do not have an account, go to the DfE Sign in page and then:

  • select ‘create a DfE Sign-in account‘
  • enter your details and email address
  • add the verification code
  • create a password (at least 14 characters)
  • request access to your organisation

When you have a DfE Sign-in account and are logged in, you can select the:

  • ‘Request access to a service’ link on the ‘My services’ page
  • organisation you want access to the service for
  • service from the options: 'Manage eligibility for childcare support'
  • sub-service: ‘MEFCS – Local Authority Role’

When you have added the service, you can use DfE Sign-in to access it in future.

2. What you can use the service for

You can use the service to:

  • run an eligibility check for one parent or guardian
  • run batch checks for multiple parents or guardians
  • manage foster families claiming childcare for working families
  • run and download reports
  • view guidance on running checks

3. Running checks for one parent or guardian

To run a check for one parent or guardian, choose the eligibility you want to run a check for from:

  • childcare for working families
  • early learning for 2-year-olds
  • early years pupil premium

To run a check for early learning for 2-year-olds or for early years pupil premium, you’ll need to enter the parent’s:

  • last name in full
  • date of birth
  • National Insurance number

Last names must be entered in full and exactly match how they appear on Universal Credit statements. This is because of the way the Department for Work and Pensions authenticate citizens, which requires a full last name, date of birth and National Insurance number for accuracy.

There is guidance within the service if the parent or guardian is an asylum seeker.

The result of the check will tell you whether the children of a parent or guardian are eligible.

A result of ‘may not be eligible’ means that the children of the parent or guardian are not eligible at the time of the check. If there is a result of ‘not eligible at time of check’ and the parent or guardian thinks that they are eligible, they can provide supporting evidence for you to review. There is guidance in the service on reviewing supporting evidence.

To run a check for childcare for working families, you’ll need the eligibility code, National Insurance number and child date of birth. The result of the check will tell you whether the code is valid and when it can be used. Results include:

  • code valid
  • code in grace period
  • code expired
  • code cannot be used yet
  • child too young

Result pages also include details of reconfirmation dates and grace period dates.

4. Running batch checks

To run a batch check for multiple parents or guardians, choose the eligibility you want to run a check for from:

  • childcare for working families
  • early learning for 2-year-olds
  • early years pupil premium

For all batch checks, download the batch check template provided within the service after you have chosen the eligibility type.

For each eligibility code you want to check for childcare for working families, you’ll need to add the eligibility code, a National Insurance number (this can be for a parent, guardian or partner) and the child's date of birth.

For each parent you want to check for early learning for 2-year-olds and early years pupil premium, you’ll need to add their last name, date of birth and National Insurance number.

When you have run a batch check, you’ll be able to see the status of any checks and download results for completed checks.

There is guidance in the service explaining what the results of batch checks mean.

5. Managing foster families

To add a foster family to the service, you will need the:

  • carer's details – name, date of birth and National Insurance number
  • partner's details (if applicable) - name, date of birth and National Insurance number
  • child's details – name, date of birth, postcode
  • date when the application was submitted

Based on the application submitted on date, the service will automatically apply validity, reconfirmation and grace period dates for the eligibility code.

You'll need to check the details you have entered and confirm that providing an eligibility code is consistent with a care plan before adding the family.

When the family is added to the service, the eligibility code is created, and you can share this with the social worker.

For foster families who have already been added to the service, you can:

  • view eligibility code details and reconfirmation status
  • reconfirm eligibility codes
  • change details for the carer, partner or child
  • remove the partner
  • add another child to the family

6. Running reports

You can run and download eligibility code history reports.

View eligibility code history

This report was called the Event Listing in the ECS system. Run this report to view the code history for an eligibility code. When you enter an eligibility code, the report shows details for the application and any reconfirmations. Details include:

  • submitted on date
  • validity start and end dates
  • grace period end date
  • event ID
  • personal details

7. Viewing guidance

Within the service you can read guidance on:

  • reviewing evidence for early years pupil premium and early learning for 2-year-olds
  • batch check results
  • outcome pages for childcare for working families checks
